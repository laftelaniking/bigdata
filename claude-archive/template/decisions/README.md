# 결정 기록

조언이 보정되는 유일한 경로다. **결정만 적고 결과를 안 적으면 아무 의미가 없다.**

## 쓰는 법

파일 하나 = 결정 하나. 파일명은 `YYYY-MM-DD_주제.md`.
결정한 날 앞부분만 쓰고, 결과는 나중에 채운다.

## 틀

```markdown
# 2026-09-16 조직 개편 A안 채택

## 상황
(무엇을 정해야 했나, 시한은)

## 선택지
- A안 :
- B안 :

## 고른 것과 이유
A안. 속도를 안정성보다 앞에 뒀다. 6개월 안에 점유율을 못 잡으면 의미가 없다고 봤다.

## 버린 것과 이유
B안. 수치는 더 나았지만 3년 전 같은 방식으로 실패한 적이 있다.

## 제갈량의 조언
(이때 AI 가 뭐라고 했는지 — 나중에 맞았는지 틀렸는지 보기 위해)

## 결과
(미정)

## 배운 것
(미정)
```

## 결과를 채울 때

대화에서 이렇게만 말하면 된다:

> "지난번 조직 개편 건, 팀 반발로 절반만 진행됐어. 반발 이유는 일정이었고."

그러면 해당 파일의 `결과`·`배운 것` 이 채워진다.
